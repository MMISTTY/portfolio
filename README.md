## What each project will include

- **Overview:** the problem, intended users, and why it matters.
- **My contribution:** the work I completed and credit for collaborators or external resources.
- **Implementation:** technologies, architecture, and key design decisions.
- **Demo:** screenshots or real sample input and output.
- **Reproduction:** prerequisites, installation, and verified run instructions.
- **Validation:** tests or other evidence, results, and known limitations.

6. Pin the strongest projects on the GitHub profile.
